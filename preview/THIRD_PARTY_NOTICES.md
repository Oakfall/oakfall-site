# Theme palette acknowledgements

Oakfall's **VS Code Modern** palette adapts the Light Modern and Dark Modern colours from [Microsoft Visual Studio Code](https://github.com/microsoft/vscode/tree/main/extensions/theme-defaults/themes).

Oakfall's **GitHub** palette adapts [GitHub's VS Code theme](https://github.com/primer/github-vscode-theme) and its [Primer Primitives 7.10.0](https://github.com/primer/primitives) colour tokens. Secondary text colours and accent assignments are adjusted for Oakfall's surfaces. These are Oakfall adaptations, not the complete upstream editor themes or an endorsement by their authors.
